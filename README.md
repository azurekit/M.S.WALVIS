# 🚢 Cruzeiro Ushuaia

Um jogo de investigação e raciocínio lógico desenvolvido em **C# e Windows Forms**, ambientado em um cruzeiro marítimo onde cada ambiente esconde um desafio e cada personagem pode guardar uma nova pista.

## 📖 Sobre o projeto

A bordo do Cruzeiro Ushuaia, o roubo repentino de 'Rosa' chama a atenção dos investigadores Koala e Gio, que partem numa grande investigação.

Durante três dias, o jogador deverá investigar diferentes situações, explorar a embarcação, conversar com seus habitantes e solucionar desafios para descobrir o que está por trás de cada acontecimento.

A investigação é dividida em três atos, cada um composto por três fases. Para avançar, será necessário superar minigames que envolvem raciocínio lógico, estratégia, organização e resolução de problemas.

## 🎮 Gameplay

O jogo, baseado no princípio *point and click*, apresenta diferentes mecânicas, desenvolvidas especialmente para cada etapa da investigação.

Entre os principais recursos estão:

- **Minigames:** desafios de raciocínio lógico com mecânicas variadas.
- **Investigação:** exploração e descoberta de pistas por meio de cutscenes.
- **Personagens:** interação com diferentes habitantes do cruzeiro.
- **Sistema de pontuação:** classificação de até três (quatro!) estrelas por fase.
- **Rejogabilidade:** possibilidade de repetir desafios e melhorar resultados.
- **Loja:** gaste seus pontos comprando roupas para o personagem na loja.

## 🗺️ Estrutura do jogo

O jogo é dividido em três atos, cada um representando um dia de investigação.

| Ato | Fases |
|:---:|:---:|
| I | 3 fases |
| II | 3 fases |
| III | 3 fases |

Ao todo, são nove fases que compõem a narrativa principal do jogo.

## 🎨 Direção artística

Todas as artes, elementos visuais e musicais do Cruzeiro Ushuaia foram feitos manualmente pela equipe, desde os personagens até os cenários e demais elementos gráficos.

**Nenhum recurso de inteligência artificial generativa foi utilizado na criação dos visuais do jogo.** Todo o trabalho artístico foi produzido de forma autoral, valorizando a identidade visual e o processo criativo da equipe.

Durante o desenvolvimento, foram trabalhados conceitos como:

- Programação Orientada a Objetos (POO).
- Estruturas condicionais e de repetição.

- Geração de desafios com elementos aleatórios e semi aleatórios.
- Gerenciamento de estados e progressão de jogo.

## 💻 Como executar o jogo

### ▶️ Executando o jogo

Não é necessário instalar ferramentas de desenvolvimento ou compilar o projeto para jogar.

1. Baixe ou clone este repositório.
2. Acesse a pasta `bin/Debug`.
3. Localize e execute o arquivo `ProjetoCruzeiro.exe`.

> **Importante:** mantenha todos os arquivos e pastas que acompanham o executável, pois eles contêm recursos necessários para o funcionamento do jogo, como imagens, vídeos e outros assets.

### 🛠️ Executando pelo código-fonte

Para visualizar ou modificar o código do projeto:

1. Instale o [Visual Studio](https://visualstudio.microsoft.com/pt-br/).
2. Abra o arquivo `.slnx` do projeto.
3. Aguarde o carregamento das dependências.
4. Execute a aplicação pressionando `F5` ou `Ctrl + F5`.
